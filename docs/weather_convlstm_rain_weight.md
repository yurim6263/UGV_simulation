# ConvLSTM 강수 가중 손실 실험 (채택하지 않음)

공식 모델(`backend/data/weather/convlstm.pt`)의 약점은 강한 비(≥1 mm/h) 탐지였다. 평균제곱오차로 학습해서 강한 비를 평균 쪽으로 낮게 예측한다. 팀 노트북의 강수 임계 구간(0.5, 2, 5, 8 mm/h)을 참고해, 정답 강수가 임계를 하나 넘을 때마다 강수 채널의 손실 가중치를 +1 하는 `--rain-weight 1.0`으로 같은 설정(은닉 32x32, 16에폭 상한, 에폭마다 학습 창 25%, 시드 7)에서 다시 학습했다.

```
cd backend
python scripts/train_convlstm.py --epochs 16 --rain-weight 1.0 --tag rainw
```

결과 파일은 공식 모델을 덮어쓰지 않고 `convlstm_rainw.pt`, `convlstm_rainw_metrics.json`으로 따로 저장했다. 학습은 검증 손실이 줄지 않아 14에폭에서 멈췄고 최적은 10에폭(검증 가중 손실 0.1759), 소요 약 42분(CPU)이다.

## 채택 판단은 검증 구간으로만

시험 구간(2022-07-01 이후)을 보고 고르면 시험 구간에 맞춘 선택이 되므로, 채택 여부는 검증 구간(2022 상반기)의 강수 지표로 판단했다. 시험 구간 숫자는 기록용이다.

| 검증 구간 (1/2/3시간 뒤) | 공식 모델 | 강수 가중 모델 |
|---|---|---|
| 강수 ≥ 1 mm/h CSI | 0.325 / 0.106 / 0.052 | 0.353 / 0.168 / 0.068 |
| 강수 ≥ 0.1 mm/h CSI | 0.639 / 0.502 / 0.416 | 0.633 / 0.504 / 0.424 |
| 강수 MAE (mm/h) | 0.0514 / 0.0707 / 0.0794 | 0.0537 / 0.0754 / 0.0870 |

## 결론: 맞교환이라 공식 모델을 유지한다

- **얻은 것**: 강한 비 탐지가 좋아졌다 (검증 CSI@1mm 세 예측 시간 모두 상승, 시험 구간 1시간 뒤에는 지속성 수준). 그래도 2, 3시간 뒤는 지속성보다 낮다.
- **잃은 것**: 강수 평균 오차가 모든 예측 시간에서 나빠져, 공식 모델에서는 있던 지속성 대비 우세(강수 MAE)가 시험 구간에서 "단정 불가"로 내려갔다. 기온, 이슬점, 풍속, 안개 오차도 조금씩 나빠졌다 (가중치가 강수 채널에만 걸려도 공유하는 은닉 상태가 영향을 받은 것으로 보이며, 원인은 확인하지 않았다).
- 이 시스템에서 예보는 위험도 예보 레이어(평균에 가까운 값이 쓰임)를 만들 때 쓰이는데, 사건 탐지가 조금 좋아지는 대신 전체 오차가 나빠지는 모델로 바꾸면 위험도 예보 레이어, 예보 오차 보고, 편성 저장본, 필요하면 NSGA-II까지 다시 만들어야 한다. 얻는 것이 그 비용에 비해 작다고 판단해 채택하지 않았다.
- 가중치 값(1.0) 하나만 시험했다. 다른 값이나 강수 전용 출력 머리를 따로 두는 구조는 시험하지 않았다. 한 번의 학습 결과이므로(시드 1개) 차이의 일부는 학습 우연일 수 있다.
