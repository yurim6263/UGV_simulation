# 기상 악영향 지표 (지도 표시 "기상")

지도의 위험도(`normalized_c_total` 등)는 지형과 날씨가 섞인 값이라 날씨만 따로 보이지 않는다. 위험도 31장의 분산을 나눠 보면
**칸마다 다른 고정분(지형 등)이 종합 92%, 기동성 95%, 센서 85%** 이고, 시간에 따라 변하는 몫(날씨)은 각각 8%, 5%, 15%뿐이다. 그래서 위험도 색만으로는 날씨가 잘 안 보인다.
이 지표는 원시 기상(ERA5-Land)에서 비, 안개 가능성, 토양수분, 바람을 하나(0~1)로 합쳐 지도 탭의 "기상"으로 보여 준다.

코드: `backend/app/weather/scenario_index.py`(계산), `backend/app/api/weather_map.py`(API), `frontend_js/src/replay/WeatherLegend.jsx`(범례).
테스트 `backend/app/tests/test_weather_index.py`. 자료 받기 `backend/scripts/download_era5_scenario.py`, 정합 점검 `backend/scripts/check_weather_alignment.py`.

## 지금 상태 (2026-10-29)

**기본 시나리오가 2022-08-20 22:00 UTC~(ERA5-Land 실제 날씨)로 바뀌었다.** 위험도 레이어도 같은 ERA5로 우리가 직접 만들었으므로([ltwr_generation.md](ltwr_generation.md)) 지표와 위험도가 같은 날씨에서 나온다. 날짜 불일치 문제는 기본 시나리오에서 없어졌다.

- 자료 파일 `backend/data/weather/era5_scenario.nc`는 ERA5-Land 2022-08-19~21의 이 지역 조각(55시간, 10x11칸, 약 200KB)이고 `scripts/extract_era5_scenario.py`로 월별 파일에서 만든다. git에 둔다. 파일이 없으면 지표를 만들지 않고 "표시할 수 없음"과 이유를 알린다 (다른 날의 값으로 대신하지 않는다).
- 지표는 LTWR 과 같은 강수/토양수분 곡선(`app/weather/curves.py`)과 팀 노트북의 안개 식(`app/weather/fog.py`)을 쓴다. 구역 평균은 시나리오 시작 0.62(비 3.4 mm/h)에서 끝 0.45(비 1.0 mm/h)로 뚜렷이 변하고, 지도에서 보라색 농도 변화로 보인다.
- 지표와 위험도(종합)의 시간 변화 상관은 0.99(`check_weather_alignment.py`)다. **같은 ERA5에서 만든 값이라 당연한 숫자이고 독립적인 검증이 아니다.**
- 안개 확률은 이 시나리오 밤에 약 1로 포화한다(이슬점 차 0.3℃, 풍속 1.6 m/s). 지표가 그 항(0.3)만큼은 항상 높게 깔리는 이유다.
- 시나리오 시각(표준 시간대 정보 없음)은 UTC로 간주한다. 현지 시각이면 `WEATHER_UTC_OFFSET_H=2`(폴란드 여름).

### 이력: 팀 원본 데이터(2023-06-30 22시 사례)의 날짜 조사

팀 원본 위험도(`MAP20KM_DIR=map_20km`)의 날짜는 확인하지 못했고(문서가 엇갈림: 위험도 2023-06-30, 사례 폴더 `15_Fog-driven_20230726_0300`, 노트북 `t_start` 2024-07-03), ERA5 2023-06-30과 2023-07-26 두 후보를 받아 위험도와 시간 변화 상관을 비교했으나 **위험도가 5시간 동안 한 방향으로만 변해서 상관 +1.00이 여러 시작 시각에서 나와 날짜를 구분할 수 없었다.** 6/30(상관 0.38)도 7/26도 확정하거나 배제하지 못했다. 이 조사 때문에 팀 원본의 날씨를 맞추는 대신 날짜를 우리가 정해 위험도까지 다시 만드는 쪽으로 방향을 바꿨다. 받아 둔 2023 자료(`era5_2023-06-30.nc`, `era5_0726.nc`)는 git에 없다.

### 자료를 다른 날짜로 바꾸는 법

1. 월별 파일(2018~2022)에 있는 날짜: `python scripts/extract_era5_scenario.py --start <앞날 00:00> --end <끝>`. 2023년 이후는 `python scripts/download_era5_scenario.py --dates ...`(본인의 Copernicus CDS 계정 키 `~/.cdsapirc`와 `pip install cdsapi` 필요, 키는 저장소에 쓰지 않는다).
2. 위험도 레이어도 같은 날짜로 만들어야 한다: `python scripts/build_ltwr_layers.py --start <시각>` (ltwr_generation.md 6절).
3. 서버를 다시 시작할 필요는 없다 (파일 수정 시각이 바뀌면 지표 파일을 다시 읽는다. 위험도 데이터는 서버 시작 때 읽는다).

## 계산 (모두 가정값, 보정하지 않았다)

| 요인 | 입력(ERA5-Land) | 0~1로 바꾸는 기준 | 가중치 |
|---|---|---|---|
| 비 | `tp`(누적 → 시간당 mm/h, 기존 `era5.rain_rate_mm`) | 5 mm/h 이상이면 1 | 0.4 |
| 안개 가능성 | `t2m - d2m`(이슬점 차), `u10,v10`(풍속) | 이슬점 차 0K → 1, 3K 이상 → 0, 곱하기 풍속 4 m/s 이상이면 0 (약할수록 1) | 0.3 |
| 토양수분 | `swvl1` | 0.15 → 0, 0.45 → 1 | 0.2 |
| 바람 | `u10,v10` | 15 m/s 이상이면 1 | 0.1 |

지표 = 가중합. 시간(턴 10분)은 시간별 값을 선형 보간하고, 원래 0.1° 격자에서 요인을 계산한 뒤 작전 구역 격자(200m)로 선형 보간한다. ERA5-Land는 바다 칸이 비어 있어 가장 가까운 육지 값으로 채운다.

## 한계 (화면의 "?"에도 같은 내용이 있다)

- **측정값이 아니라 가정이 들어간 추정이다.** 가중치와 기준은 근거 없이 정했다. 위험도(`c_mob`, `c_sen`)와 같은 척도가 아니고, 위험도 계산에는 쓰이지 않는다(보기 전용).
- **안개/시정은 ERA5-Land에 없다.** 이슬점 차와 바람으로 추정한 규칙일 뿐이다.
- **거친 격자**: 0.1°는 약 11km x 6km라 작전 구역(약 20km)에 2~4칸이다. 지도의 부드러운 모양은 보간이고 세부 위치별 차이를 말해 주지 않는다. 화면 범례도 "거친 격자를 보간한 값"이라고 적는다.
- **지형의 영향 없음**(순수 기상). 위험도에서 날씨만 떼어낸 것도 아니다.
- **날짜와 시각이 맞는지 확인 전**: 위 "지금 상태" 참고. `check_weather_alignment.py`는 시간 변화의 방향만 비교하며(31개 시각, 한쪽으로 변하는 추세), 맞다는 증명이 아니다. 낮거나 음수면 날짜/시각 불일치를 의심한다.
- 예보(예보 탭)에는 쓰지 않는다. 예보 탭은 위험도 예보만 있다.
- 값이 약한 날씨(비 없음, 바람 약함)에서는 0~1 고정 척도에서 지표가 낮아 지도가 옅게 보인다. 척도를 늘려 보이게 하지 않았다 (절대 크기를 읽을 수 있게). 시간 변화 그래프만 세로를 0~0.5 이상으로 맞춘다.

## 화면: 지도 오버레이와 "기상" 탭

- 지도 표시 "기상"(오버레이): 0~1 절대 척도의 보라색 농도. 날씨가 구역 안에서 거의 균일해서(ERA5 약 11km 격자) 위치 차이는 거의 없고 구역 전체가 같은 농도로 칠해진다. 시간 슬라이더로 변화를 본다.
- 우측 "기상" 탭(시계열 그래프): 기상 악영향 지표와 같은 시점의 위험도(종합) 구역 평균을 한 그래프에 겹쳐 그리고, 비, 안개 확률, 토양수분, 바람을 따로 그린다. 그래프를 누르면 해당 시점이 선택된다. 5시간 동안의 날씨 변화와 위험도 반영은 지도보다 이쪽이 잘 보인다 (`GET /api/map/weather/info`의 턴별 값, `risk_total` 포함).

## 화면 확인 상태

- 자료가 없을 때("표시할 수 없음")와 기본 시나리오(ERA5 2022-08-20)가 있을 때의 화면을 모두 확인했다. 지휘관 화면에서 시나리오 시작에 지표 0.62, 비 3.4 mm/h, 안개 확률 99%, 바람 2.4 m/s, 토양수분 0.35가 보이고 지도 전체가 보라색으로 칠해진다.
- 시나리오 후반(비 약해짐)에는 색이 옅어진다. 날씨의 영향이 지도에서 "보이는" 목표는 이 시나리오(비와 안개가 있는 구간)에서 달성했다. 다만 칸마다의 차이는 거의 없고(ERA5 0.1° 보간) 시간에 따른 변화가 보이는 것이다.
